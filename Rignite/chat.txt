## 3. Code Examples

### Python (`requests`)
```python
import requests

url = "https://tg-game-sessionmaker.onrender.com/api/get-init-data"
payload = {
    "bot": "catizenbot",
    "short_name": "gameapp",
    "start_param": "rp_12345"
}

response = requests.post(url, json=payload)
data = response.json()

# Raw string for HTTP Authorization headers / game requests
init_data = data["initData"]

# URL to open the game directly in any browser
launch_url = data["launch_url"]

print("initData:", init_data)
print("Launch URL:", launch_url)
```
